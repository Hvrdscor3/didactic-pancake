Conectar tu correo

Elige tu proveedor. Cada uno necesita su propio Client ID — se guarda solo en tu navegador, nunca se comparte.

  1. Ve a console.cloud.google.com/apis/credentials
  2. Crea un proyecto (o usa uno existente) y habilita la Gmail API
  3. Configura la pantalla de consentimiento OAuth (modo "Externo" y agrégate como usuario de prueba)
  4. Crea credenciales → ID de cliente de OAuth → tipo "Aplicación web"
  5. En "Orígenes autorizados de JavaScript" agrega el origen desde donde abras este archivo
  6. Copia el Client ID (termina en .apps.googleusercontent.com) y pégalo abajo
Nota: los archivos .html abiertos con doble clic (file://) no funcionan con estos OAuth. Ábrelo desde un servidor local o un hosting, y usa esa misma URL como origen autorizado.
  1. Ve a portal.azure.com → "Microsoft Entra ID" → "Registros de aplicaciones" → "Nuevo registro"
  2. En "Tipos de cuenta admitidos" elige "Cuentas en cualquier directorio organizativo y cuentas Microsoft personales"
  3. En "Autenticación" → "Agregar una plataforma" → "Aplicación de página única (SPA)" → agrega como URI de redirección la misma URL desde donde abras este archivo
  4. En "Permisos de API" → "Agregar un permiso" → "Microsoft Graph" → "Permisos delegados" → marca Mail.ReadWrite y User.Read
  5. Copia el "Id. de aplicación (cliente)" desde "Resumen" y pégalo abajo
Nota: igual que con Gmail, esto no funciona abierto con doble clic (file://). Usa la misma URL de hosting que registraste como URI de redirección.
